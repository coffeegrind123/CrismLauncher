# Crism Launcher

[![Build Status](https://github.com/coffeegrind123/CrismLauncher/actions/workflows/ci.yml/badge.svg)](https://github.com/coffeegrind123/CrismLauncher/actions/workflows/ci.yml)
[![Latest Release](https://img.shields.io/github/v/release/coffeegrind123/CrismLauncher)](https://github.com/coffeegrind123/CrismLauncher/releases/latest)

A Prism Launcher fork with modified mod downloading behavior to bypass blocked mod restrictions.

## Changes from Upstream

**Mod Download Modifications:**
- Bypasses "blocked mods" dialog for CurseForge/Flame modpacks
- Automatically generates download URLs for mods that lack official third-party download links
- Treats ATLauncher browser-required downloads as direct downloads
- Allows automatic installation of previously restricted mods
